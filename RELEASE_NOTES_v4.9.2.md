# EF Johnson 5300ES Feature Manager v4.9.2

**Portable Windows x64 freeware — closed source**

This release adds the custom Lightning radio control-head Windows application icon while retaining the validated feature-management interface.

Features include Current and Proposed feature panels, category shortcuts, preferred feature preset with hover explanation, output filename preview, and saving a new `.opt` file without overwriting the original.

**Planned release archive:** `EFJ5300ES_Feature_Manager_v4.9.2_Win64.zip`

Extract all files together into a writable folder and run the executable. Keep the included bitmap assets beside it.

The executable is unsigned; Windows SmartScreen may display a warning. Earlier versions are historical development builds and are not available as downloads.

This release archive has **not yet been published**. The checksum file will be added after verifying the final release ZIP.
