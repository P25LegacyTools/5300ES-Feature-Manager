# EF Johnson 5300ES Feature Manager

Independent, closed-source freeware utility for compatible legacy EF Johnson 5300ES `.opt` files.

**Current release:** v4.9.2 (portable Windows x64). The release binary will be published separately after approval.

The utility provides Current and Proposed feature views, category navigation, a preferred feature preset, output filename preview, and non-overwriting save behavior.

This project is not affiliated with or endorsed by EFJohnson or JVCKENWOOD. Use only with equipment and systems you are authorized to manage. Do not use to defeat trunking system authentication.
